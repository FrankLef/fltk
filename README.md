**fltk** is a lightweight package to simplify and streamline Ephel's projects written in Python.

## Introduction

Toolkit used in Ephel's Python coding projects. It contains 2 very important
applications:

- `specs`: This is the class management the dataframes containing all the technical specifications for the project.
- `workflow`: This is the class for the command line interface (CLI).
